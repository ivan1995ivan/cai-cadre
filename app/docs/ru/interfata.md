# Вид программы: «Классическая программа»

CAI CADRE по умолчанию выглядит как **классическая офисная программа**: окно со строкой заголовка, строкой меню, панелью
инструментов, открытыми окнами-вкладками и строкой состояния внизу. Окна и панели светло-серые, поля и таблицы белые с
тонкой рамкой, строки таблиц плотные, с линиями сетки, выбранная строка выделяется голубым, как в Windows.

## Что на экране, сверху вниз

1. **Строка заголовка**: *CAI CADRE — название предприятия* (на платформе с несколькими базами — и имя базы).
2. **Строка меню**:
   - **Файл** — Стартовая страница, Сроки и оповещения, Мой кабинет, **Избранное** (и *Добавить окно в избранное*), Мой
     профиль, **Тема**, **Язык**, Сменить базу (на платформе), **Выход**;
   - **разделы главного меню** (Предприятие, Сотрудники, Приказы, Отпуска и рабочее время, Зарплата, Обучение и учёт,
     Отчёты, Администрирование): в каждом — реестры, затем отчёты раздела и подменю **Классификаторы**. Видно ровно то, что
     у вас есть в меню: права роли, отметки в [Роли → Главное меню](help:admin/roles); модули, выключенные в
     [Константы → Модули](help:admin/constants), не показываются. Порядок и названия разделов — из
     [Главного меню](help:admin/main-menu). Раздел открытой страницы выделен жирным;
   - **Окна** — список открытых окон (`` Alt+` ``), *Закрыть окно* (Esc), *Закрыть все*, Назад / Вперёд и открытые окна по
     номерам;
   - **Справка** — инструкция экрана (F1) и *О программе*.
3. **Панель инструментов** (маленькие значки; при наведении мыши появляется подсказка):

   | Кнопка | Что делает |
   |---|---|
   | ← → | Назад / Вперёд (Alt+← / Alt+→) |
   | Домик | Стартовая страница |
   | **Создать** | Кнопка «новый» открытого окна: *Новый сотрудник*, *Новый приказ*, *Новый расчёт*, *Добавить* в классификаторах |
   | **Сохранить** (Ctrl+S) | Сохраняет открытую форму, как её кнопка *Сохранить* (или *Да* на «Сохранить изменения?»); активна только при несохранённых изменениях |
   | **Печать** | Кнопка печати окна: диалог печати (список сотрудников, приказ, табель, расчётная ведомость...) |
   | **Excel** | Сохраняет список окна в Excel (та же команда, что значок в углу таблицы) |
   | **Обновить** | Заново запрашивает данные окна с сервера; при несохранённых изменениях — сначала сохраните |
   | **Поиск** | Переводит курсор в поле поиска окна |
   | **Открытые окна** | Список открытых окон (`` Alt+` ``) |
   | ? | Инструкция экрана (F1) |

   Кнопка, которой у открытого окна нет (например, *Создать* в личном деле или *Excel* в форме без списка), серая, а её
   подсказка объясняет почему.
4. **Открытые окна-вкладки**: каждая открытая страница остаётся вкладкой; ✕ на вкладке (или щелчок колёсиком мыши)
   закрывает её, **Esc** закрывает активное окно. При несохранённых изменениях программа сначала спросит «Сохранить
   изменения?».
5. **Активное окно**.
6. **Строка состояния**: связь с сервером (*Подключено* / *Нет связи с сервером*, красным), пользователь, роль, где вы
   находитесь (раздел → экран), **колокольчик** уведомлений с их числом, **кто онлайн** (для тех, кто видит
   пользователей) и версия программы.

## Меню с клавиатуры

- **Alt** (нажать и отпустить) выбирает строку меню: буквы доступа подчёркиваются; **←/→** — между меню, **↓** или
  **Enter** — открыть меню.
- **Alt + подчёркнутая буква** сразу открывает меню (например, Alt+Ф — Файл, Alt+С — Сотрудники).
- В меню: **↑/↓** — выбор, **→** — в подменю (или к следующему меню), **←** — из подменю, **Enter** — выполнить,
  **Home / End** — первая / последняя строка, буква — строка, начинающаяся с неё.
- **Esc** закрывает подменю, затем меню, затем строку меню (только после этого Esc закрывает открытое окно).

## Формы, таблицы, диалоги

- В формах подпись стоит **слева от поля**, в колонке одной ширины; группы полей — **в рамке с заголовком** (как
  *GroupBox*).
- В таблицах сетка по всем ячейкам, серая шапка и строки ~24 px; выбранная строка — голубая.
- Диалоговые окна имеют **свою строку заголовка** с ✕, кнопки **OK / Отмена** — справа внизу.
- Без скруглённых углов, больших теней и анимаций; кнопки прямоугольные, со сдержанным объёмом (в
  [Моём профиле](help:profile) — *Плоские (2D)* для кнопок без объёма).

## Тема: как выбрать

- **Для всего предприятия**: [Администрирование → Настройки → Константы](help:admin/constants), вкладка *Тема* (и в
  мастере установки). Тема по умолчанию для новых установок — **Классическая программа**.
- **Для себя**: [Мой профиль](help:profile) → *Тема* или меню **Файл → Тема**. *Тема предприятия* — как выбрано в
  Константах.
- Темы:
  - **Классическая программа** и **Классическая программа, тёмная** — вид, описанный выше;
  - **Свежая зелень**, **Бирюзовая**, **Синяя**, **Тёмная**, **Как в 1С (жёлтая)** — вид с меню слева (разделы сверху
    или всё меню слева) и панелью открытых окон внизу, как раньше;
  - **Автоматически** — по настройке компьютера: днём тема предприятия, ночью её тёмный вариант (для *Классической
    программы* — *Классическая программа, тёмная*).

## Панель функций

При включённой [Панели функций](help:panel) разделы больше не стоят рядом вкладок под шапкой (это дублировало бы строку
меню): первая строка в меню каждого раздела — **Панель функций**, она открывает панель раздела (схема работы, реестры,
классификаторы, отчёты).

## На телефоне

На узком экране строка меню сворачивается в кнопку **☰** на панели инструментов (разделы с функциями, избранное,
профиль, тема, язык, справка, выход). На панели инструментов остаются основные кнопки (Назад, Стартовая, Создать,
Сохранить, Печать, Обновить, Открытые окна), в строке состояния — связь, пользователь, уведомления.
