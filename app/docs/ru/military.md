# Воинский учёт

**Дополнительный модуль, по умолчанию выключен.** С 02.07.2023 (Закон 112/2023) воинский учёт военнообязанных больше не
обязателен для хозяйствующих субъектов. Фирма, которая всё же его ведёт (например, по запросу военного центра), включает
его в **Администрирование → Константы → Модули → Модуль «Воинский учёт»**.

С **выключенным** модулем страница *Воинский учёт*, вкладка в личном деле, военные отчёты, военные справочники и раздел в
личной карточке не показываются; API карточки отвечает «не найдено», а отчёты — «нет доступа». Введённые раньше данные
остаются в базе и появляются снова, когда модуль включают.

С **включённым** модулем работодатель ведёт учёт призывников и военнообязанных и сообщает в территориальный военный центр
об изменениях (ПП 631/2003). Карточка учёта каждого сотрудника — в личном деле, вкладка **Воинский учёт** (категория,
группа, состав, звание, ВУС, военный центр, годность, спецучёт, военный билет). Эта страница собирает данные по всему
предприятию.

| Вкладка | Что показывает |
|---|---|
| **Реестр** | Призывники и военнообязанные на выбранную дату со всеми данными учёта; сколько военнообязанных и сколько призывников |
| **Без карточки** | Работающие мужчины 16–60 лет без заполненной карточки — нужно запросить военный билет или приписное свидетельство |
| **Изменения за месяц** | По призывникам и военнообязанным: кто принят, уволен, переведён в месяце (с приказом) и у кого изменились данные (фамилия, адрес, семейное положение, телефон, образование, семья, данные учёта) — ежемесячная информация в военный центр |
| **Призывники** | Сотрудники со статусом призывника и мужчины 16–27 лет — годовой список |

На каждой вкладке есть фильтры (дата или месяц, подразделение), **Excel** и **Печать** с шапкой предприятия.

Изменения данных берутся из журнала аудита: всё, что меняется в карточке сотрудника, само попадает в отчёт месяца.

Право: *Воинский учёт* (просмотр / экспорт) — выдаётся только при включённом модуле. Отчёты есть и в
**Отчёты → Воинский учёт**.
