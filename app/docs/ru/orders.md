# Приказы

**Новый приказ:** выберите вид (сгруппированы по A–G: трудовые отношения, отпуска, рабочее время, оплата труда,
дисциплина, профессиональные, организационные), дату и сотрудника (в сводных приказах — нескольких). Заголовок, правовые
основания и преамбула берутся из вида приказа и могут быть изменены.

**Шапка**, как в 1С — подпись слева от поля, в две колонки: слева *№ и дата* (пустой номер = следующий при подписании),
заголовок, **правовые основания** и преамбула; справа основание (заявление, ходатайство), заключительные пункты,
подписант (должность и имя в одну строку) и визы. В **правовых основаниях** выбирается **одна или несколько** статей;
преамбула составляется сама, по актам («În temeiul art. 55 lit. a) și art. 60 din Codul muncii nr. 154/2003, …»), и её
можно поправить вручную. Основания по умолчанию для каждого вида (тоже одно или несколько) задаются в *Настройки → Виды
приказов*. Уход из приказа с несохранёнными изменениями (Esc, ✕, другая вкладка) спрашивает «Сохранить изменения?».

**Пункты «ПРИКАЗЫВАЮ:»**: для каждого сотрудника заполните параметры (должность, отделение, ставка, оклад, период отпуска,
причина увольнения...) — в две колонки, с подписью слева; длинные поля (трудовое отношение, причина) занимают всю строку. Текст пункта составляется сам при сохранении; «написать вручную» — для собственного текста.
В отпусках дни считаются без нерабочих праздничных дней (дата окончания рассчитывается сама).

**Подписание** присваивает номер в журнале (например, 125-p для личного состава, 38-c для отпусков, 12-d для командировок;
без суффикса — приказы по основной деятельности) и применяет приказ к личным делам: приём, перевод, изменение ставки или
оклада, замещение, приостановление, прекращение, отпуска, командировки и направление на повышение квалификации, взыскания,
утверждение штатного расписания. Подписанный приказ больше не изменяется.

**Отмена** оформляется приказом: «Отменить приказом» создаёт черновик приказа об отмене; при его подписании действия
отменённого приказа откатываются (приём исчезает, перевод возвращается, отпуск удаляется, увольнение отменяется).

**Печать:** приказ с гербом, визами и таблицей «Ознакомлен(а)»; **выписка** для одного сотрудника (кнопка у пункта).
**Журнал приказов** показывает приказы по журналу и году, в порядке номеров, с пропущенными номерами.

Шаблоны текстов пунктов меняются в Администрирование → Настройки → Виды приказов.
