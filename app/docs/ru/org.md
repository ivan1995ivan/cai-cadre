# Учреждение и подразделения

Подразделения ведутся в виде дерева: департаменты, отделения, блоки, лаборатории, административные службы. Для каждого
заполняется тип (клиническое, параклиническое, амбулаторное, административное), число коек, заведующий и — для отделений
с **вредными условиями** (ПП 1223/2004: анестезиология и интенсивная терапия, радиология, инфекционные болезни…) — дни
дополнительного отпуска и сокращённый рабочий день. Эти значения дальше используются в остатках отпусков и графиках
работы.

**Импорт из Excel:** скачайте шаблон, заполните по одной строке на подразделение (родительское — по коду или наименованию,
выше в файле) и загрузите его. Сначала выполняется проверка, затем **Импортировать**.

Данные предприятия (наименование RO / RU / EN, правовая форма, IDNO, CAEM, адрес, руководитель, главный бухгалтер,
ответственный за кадры, логотип для шапки форм) заполняются в **Администрирование → Настройки → Константы**.
