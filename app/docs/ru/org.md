# Предприятие и подразделения

Подразделения ведутся в виде дерева: департаменты, отделы, службы, цеха, филиалы, склады. Для каждого заполняется тип
(департамент / дирекция; отдел / служба / бюро; цех / производственный участок; филиал / обособленное подразделение;
склад; другое), руководитель и — для мест с **вредными условиями труда** (ТК ст. 96, 121, 139) — дни дополнительного
отпуска (не менее 4, ТК ст. 121) и сокращённая рабочая неделя (не более 35 часов, ТК ст. 96). Эти значения переходят в
остатки отпусков и в графики работы.

**Импорт из Excel:** скачайте шаблон, заполните по одной строке на подразделение (родительское — по коду или наименованию,
выше в файле; тип — код или начало наименования, например «atelier») и загрузите его. Сначала выполняется проверка, затем
**Импортировать**.

Данные предприятия (наименование RO / RU / EN, IDNO, адрес, директор, начальник отдела кадров, шапка форм) заполняются в
**Администрирование → Настройки → Константы**.
