# Трудовые договоры

Реестр всех трудовых отношений (индивидуальных трудовых договоров): основная работа, совместительство, замещения,
договоры оказания услуг. Фильтр **Истекающие сроки** показывает срочные договоры и испытательные сроки, которые заканчиваются в течение
30 / 60 / 90 дней — прошедшие сроки красные, близкие оранжевые. Двойной клик открывает карточку сотрудника.
