# Ведомость на выплату

**Ведомость на выплату** (меню *Ведомости на выплату*) — второй документ по зарплате, после расчёта: **здесь удерживаются
НКМС 9 %, льгота и подоходный налог 12 %.** В каждой строке: **брутто** (выплачиваемый доход), **льгота**, **НКМС**,
**налог**, прочие удержания и **сумма к выплате**.

**Новая ведомость**: что выплачивается (аванс или зарплата), основание, способ (карта и наличные, только карта, только
наличные) и дата. Из утверждённого расчёта она создаётся сразу кнопкой **«Ведомость на выплату»**.
- **Зарплата по расчёту**: только сотрудники выбранного расчёта, не больше его суммы; месяц — месяц расчёта.
- **Зарплата по остатку**: без расчёта-основания — всё, что осталось выплатить за месяц, по всем утверждённым расчётам
  месяца.
- В обоих случаях **брутто** — начисленное минус уже выплаченное за месяц. **Налоги считаются нарастающим итогом за
  месяц**: со всего дохода, выплаченного в месяце до сих пор (включая аванс), — НКМС с базы НКМС, месячная льгота (1/12
  годовой льготы по **заявлению о льготах**: личная, повышенная, на супруга / супругу, на иждивенцев), налог с базы налога
  минус НКМС минус льгота — и удерживается **разница** с уже удержанным. Так аванс и зарплата вместе удерживают ровно
  налог месяца.
- **Аванс**: процент из констант («Аванс», по умолчанию 40 %) × должностной оклад × ставка основного места, округлённый до
  лея — брутто; из него удерживаются НКМС 9 % и налог 12 % с остатка (месячная льгота — при выплате зарплаты). Аванс не
  выплачивается по расчёту.

**Форма**: вверху заголовок — *Ведомость на выплату № … от …* —, вид (зарплата / аванс), статус и ссылка на
расчёт-основание (щелчок открывает расчёт). Справа вверху действия; **✕** — последняя кнопка, закрывает форму. В черновике
**шапка заполняется вручную**: дата, вид, расчёт-основание (или *по остатку*), месяц (при *по остатку*), способ,
примечание; **Сохранить** её записывает. Другое основание, вид, месяц или способ **заполняют строки заново** (если есть
ручные исправления, программа сначала спросит). Если уйти из формы с несохранённой шапкой, программа спросит
**«Сохранить изменения?»** — *Да*, *Нет*, *Отмена*.

**Ручное исправление** (в черновике): введите **брутто** — налоги пересчитаются (по зарплате в той же пропорции, с
льготой); введите **сумму к выплате** — программа найдёт брутто, дающее ровно это нетто; введите **льготу, НКМС или
налог** напрямую — они останутся как введены, пересчитается только сумма к выплате. Исправленная строка отмечена ✎.
Карта выбирается для сотрудников, у которых в личном деле есть IBAN; остальные получают наличные. Строку можно убрать, а
«Заполнить заново» пересчитывает всё.

**Порядок работы**: черновик → **утверждена** → **выплачена** (дата и платёжный документ: платёжное поручение для банка
или расходный кассовый ордер). Повторно открыть может тот, у кого есть право утверждения по зарплате. Пока по расчёту есть
утверждённая или выплаченная ведомость, расчёт повторно не открывается.

**Печать и банк**: **платёжная ведомость** (с колонкой подписи для наличных и расчётом-основанием в шапке), **список для
банка** (только карты: ФИО, ИДНП, IBAN, сумма) и **файл для банка** (CSV с «;»: IBAN, ФИО, ИДНП, сумма, назначение
платежа). Точный формат, требуемый банком (MAIB, Victoriabank, Moldindconbank), настраивается при установке.

**Расчётные листки** — из ведомости на выплату зарплаты, по её сотрудникам: в каждом листке весь месяц сотрудника —
его трудовые отношения из утверждённых расчётов месяца (начисления, удержания), затем расчёт за месяц: НКМС, льгота и
налог, нетто, выплаченные аванс и зарплата, остаток. **Расчётные листки** печатает все листки, значок в строке — листок
одного сотрудника; **Расчётные листки в PDF** скачивает их (каждый сотрудник на своей странице). **Отправить листки по
почте** (из утверждённой или выплаченной ведомости) отправляет каждому сотруднику **ZIP-архив с листком в PDF**; **пароль
архива — последние 5 цифр фискального кода (IDNP)**. Отправляется только тем, у кого в личном деле есть e-mail и IDNP;
остальные показаны с причиной. Почтовый сервер настраивается в Администрирование → Настройки → Почта (e-mail). По авансу
листки не делаются. Сотрудник видит листок каждого месяца и в своём кабинете.

**Задолженность по зарплате** (вторая вкладка): на конец выбранного месяца, по сотруднику, **до налогов** — начислено
(брутто утверждённых расчётов минус прочие удержания), выплачено (выплаченное брутто, зарплата и аванс) и
задолженность. Минус означает переплату.

**Личная карточка учёта доходов за год** (приложение № 8 к ПП 697/2014) печатается из карточки сотрудника → вкладка
«Зарплата»: данные работодателя и сотрудника, льгота из заявления, затем **по каждой выплаченной ведомости** — дата,
выплаченный доход (текущий и нарастающим итогом), льгота, взносы НКМС, налогооблагаемый доход, налог рассчитанный и
удержанный (+/−). Без выплаченных за год ведомостей в карточке нет строк.

**IPC21, таблица 1** и **IALS21** (выплаченный доход, льготы, удержанные налог и НКМС) строятся по **выплаченным**
ведомостям, по дате выплаты (см. *Отчётность*).


**Месяц в режиме IT-парка**: с зарплаты по ИТД не удерживаются CNAM и налог и не даётся освобождение — к выплате брутто
минус прочие удержания; аванс выплачивается полностью. Режим — **месяца расчёта**, а не даты выплаты (зарплата за июнь,
выплаченная в июле, — по режиму июня). Договоры оказания услуг — с обычными удержаниями. Окончательно обложенная часть
каждой выплаты учитывается отдельно (для IPC21, IALS21, ISAPTI17). См. [Режим IT-парка](help:payroll/it-park).
