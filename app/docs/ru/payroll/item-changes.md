# Изменение плановых начислений

*Зарплата → Изменение плановых начислений.* Документ для изменений во вкладке «Зарплата», которым **не нужен кадровый
приказ**: исполнительный лист (алименты, удержание), профсоюзный взнос по заявлению, талоны на питание, надбавка по
внутреннему положению. Изменения с приказом (приём, перевод, оклад, надбавки, совмещение, удержание по приказу) делаются в
приказе, в таблице «Начисления и удержания» (см. *Приказы*).

**Новый документ**: номер присваивается сам (например, MA-2026-00001), дата — сегодня (меняется). В строках — **несколько
сотрудников в одном документе**:
- **сотрудник** и **трудовое отношение** (пусто — основное);
- **вид расчёта** (только те, что ставятся сотруднику, не автоматические);
- **действие**: *добавить* — новая строка; *изменить* — действующая строка этого вида закрывается накануне даты «с», а с неё
  открывается новая с новыми значениями (пустые берутся из старой); *прекратить* — действующая строка получает «по» (дату
  из «по», иначе канун даты «с»). Если у сотрудника несколько строк этого вида — выберите строку;
- **сумма / процент / количество** (по виду: фиксированная сумма и тариф требуют сумму, проценты — процент, если у вида нет
  своего; количество — для формул с `Cantitate`);
- **с** (пусто — дата документа) / **по**;
- **основание** (исполнительный лист № …, заявление от …) — видно во вкладке «Зарплата» и в пояснении строки расчёта.

**Утверждение** (право утверждения зарплаты) ставит строки во вкладку «Зарплата» каждого сотрудника, со ссылкой на документ;
ошибка (например, «нет действующего PENSIE») останавливает всё — ничего наполовину. Утверждённый документ не изменяется и не
помечается на удаление.

**Отмена утверждения** возвращает ровно сделанное: добавленные строки исчезают, закрытые получают прежнее «по». Если строку
после этого изменил другой документ (например, более поздний её прекратил), отмена останавливается с сообщением — сначала
отмените более поздний документ.

**Черновик** помечается на удаление как любой документ (окончательное удаление — *Администрирование → Удаление помеченных
объектов*).

**Печать**: простая форма с шапкой предприятия — таблица строк (сотрудник, вид, действие, сумма, %, количество, период,
основание) и подписи; тексты меняются в *Печатных формах*.

**Права**: зарплатные — видит тот, у кого «Зарплата: просмотр», пишет — «создание / изменение», утверждает — «утверждение».
