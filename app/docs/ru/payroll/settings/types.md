# Виды расчёта: формула и база

*Администрирование → Настройки → Виды расчёта.* Каждое начисление, удержание или взнос работодателя — это **вид расчёта**:
код, название (RO / RU / EN), категория, **как считается** и **что облагается**.

## Таблица

Колонка **«Из чего считается»** показывает правило каждого вида, чтобы база была видна:
- у **автоматических** — правило расчёта со значениями действующих констант. Пример, SUPL: «tariful orar × (primele 2 ore pe zi ×
  150 % + restul × 200 %), CM art. 157» (в русском интерфейсе — «часовой тариф × (первые 2 часа в день × 150 % + остальные ×
  200 %), КТ ст. 157»);
- у остальных — формула или база с названиями видов.

Далее: категория, подоходный налог, ОМС, соцстрах, «входит в средний», необлагаемый лимит и код источника дохода (IPC21 / IALS21).

## Способы расчёта

| Формула | Что делает |
|---|---|
| Автоматически | Из табеля, отпусков, больничных, приказов (оклад, постоянные надбавки, ночные, праздничные, сверхурочные, отпуск, больничный, премии, соцстрах) |
| Фиксированная сумма | Сумма из строки сотрудника (вкладка «Зарплата», приказ, документ) |
| % от оклада | SalariuFunctie × отработанная доля × процент |
| % от базы | Сумма видов базы × процент |
| Тариф × часы | Тариф из строки сотрудника × отработанные часы (+ доплата за сверхурочные и праздничные) |
| % по ступеням стажа | База × процент достигнутой ступени общего стажа |
| **Формула** | Выражение, которое пишете вы (ниже) |

**«Считается для»**: *только у кого есть строка* (по умолчанию) — вид входит в расчёт только у тех, у кого он есть во вкладке
«Зарплата»; *все сотрудники* — общий вид (например, надбавка всем по табелю), считается на каждом трудовом отношении (без
договоров оказания услуг). Ступени стажа — «для всех» (как и раньше).

## Формула

Пишется как в Excel, но по-молдавски: **аргументы разделяются «;»**, десятичные — **«,» или «.»** (`1,5` = `1.5`).
Регистр букв не важен.

- Операторы: `+ - * / ( )`; сравнения `< <= > >= = <>`; `și` / `sau` (и `and` / `or`) — «и» / «или».
- Функции: `min(a; b; …)`, `max(a; b; …)`, `round(x; n)` (коммерческое округление до n знаков), `abs(x)`,
  `daca(условие; да; нет)` (и `if`). В `daca` вычисляется только выбранная ветвь.
- `C.<код>` — константа зарплаты (например, `C.night_pct`), значение, действующее в месяце расчёта.
- `[КОД]` — уже рассчитанная сумма другого вида в той же строке (например, `[PREMIU]`).

**Переменные** (в редакторе: клик вставляет; описание — при наведении):

| Переменная | Что это |
|---|---|
| SalariuFunctie | оклад за ставку трудового отношения (оклад × ставка) |
| Norma, OreLucrate | норма часов месяца, отработанные часы (табель) |
| ZileLucrate, ZileNorma | отработанные дни; рабочие дни месяца по календарю |
| TarifOrar | SalariuFunctie / Norma |
| ParteLucrata | отработанная доля нормы (0…1), как у оклада |
| OreNoapte | ночные часы (22–06) |
| OreSarbatoare, OreOdihna | часы в праздничные и выходные дни; из них — в выходные по графику |
| OreSarbatoareInNorma, OreSarbatoarePesteNorma | те же часы в пределах месячной нормы / сверх неё (КТ ст. 158) |
| OreSuplim2, OreSuplimPeste | сверхурочные: первые 2 в день / последующие (КТ ст. 157) |
| Suma, Procent, Cantitate | из строки сотрудника (пустой Procent — процент вида) |
| Baza | сумма видов из «Базы расчёта» вида |
| SalariuMinim, SalariuMediu | минимальная зарплата, прогнозная средняя зарплата (константы) |
| NormaRaport | ставка трудового отношения (1; 0,5…) |
| VechimeAni, VechimeIntreprindereAni | общий стаж / стаж на предприятии, полных лет, на конец месяца |

**Работающие примеры** (проверены тестами):

| Что | Формула |
|---|---|
| Ночные, как автоматическое правило | `TarifOrar * OreNoapte * C.night_pct / 100` |
| Надбавка за верность 10 % от 5 лет на предприятии | `daca(VechimeIntreprindereAni >= 5; SalariuFunctie * 10 / 100; 0)` |
| Запрошенная сумма, но не выше минимальной зарплаты | `min(Suma; SalariuMinim)` |
| Процент от базы (как «% от базы») | `Baza * Procent / 100` |
| Простой (КТ ст. 80¹): 2/3 часовой ставки, не ниже минимальной за час | `max(SalariuFunctie * 2/3 / Norma; SalariuMinim / 169) * Cantitate` |

**Проверка при сохранении**: синтаксическая ошибка, несуществующая переменная, константа или вид — ошибка с **позицией**;
редактор показывает её сразу при наборе. Нельзя использовать виды, считающиеся после формул (соцстрах, соцстрах на
минимальную базу) или при выплате (налог, ОМС, аванс). **Циклическая зависимость** (A использует B, B — A; напрямую, через
базу или через [КОД]) отклоняется: «Dependență circulară: A → B → A». Код вида, используемого в формуле / базе другого, не
переименовывается и не помечается на удаление — сначала уберите его оттуда.

**Порядок расчёта** строится сам: сначала автоматические виды, затем строки, написанные вручную, и доплата до минимальной
зарплаты, затем остальные виды — каждый после тех, от которых зависит; в конце базы, соцстрах и соцстрах на минимальную базу.

**Отрицательный результат** обнуляется (начисление / удержание не может быть отрицательным), с предупреждением в
пояснении. Ошибка при расчёте (например, деление на 0 у сотрудника с Norma 0) останавливает расчёт месяца с названием вида и
сотрудника: используйте `daca(Norma > 0; …; 0)`.

## Как читать пояснение

В расчёте месяца строка вида с формулой имеет пояснение: формула со значением каждой переменной и результат, например
`TarifOrar 37,28 × OreNoapte 16 × C.night_pct 50 / 100 = 298,24`; после «;» — основание из строки сотрудника.

## «Проверить на сотруднике»

В редакторе вида выберите сотрудника и месяц, при необходимости сумму / процент / количество (воображаемая строка) и нажмите
**Проверить**. Программа считает месяц в памяти, с формулой как она написана сейчас (и не сохранена), и показывает по
каждому трудовому отношению переменные со значениями, результат и ошибки. **Ничего не сохраняется.**

## Что облагается

Группа «Что облагается»: подоходный налог, ОМС, соцстрах (флажки), «входит в средний заработок» (отпуска, больничные),
необлагаемый лимит (в месяц, в год или % средней зарплаты — часть ниже лимита не входит в базы) и код источника дохода
(IPC21 / IALS21).
