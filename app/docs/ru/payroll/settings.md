# Настройки зарплаты (константы 2026)

Для того, кто настраивает зарплату: *Администрирование → Настройки → Константы зарплаты* и *Виды расчёта*. У каждой константы
есть **«действует с»**: при изменении закона добавляется новая строка со своей датой, старая остаётся для прошлых месяцев.
Основание, ещё не подтверждённое официальным текстом, помечено **«проверить»** — значение исправляется здесь, без
программиста.

**Новые виды расчёта** (автоматические): **MINIM** «Доплата до минимальной зарплаты», **BOALAACC** «Пособие при несчастном
случае на производстве (дни работодателя)», **CASMIN** «НКСС на разницу до минимальной базы». Автоматический вид можно сделать
неактивным (например MINIM), но закон требует минимальную зарплату — предупреждение остаётся.

**При обновлении старой установки** миграция исправляет только то, что осталось с поставленным значением: минимальная
зарплата 5 500 → 6 300, средняя 17 200 → 17 400, старые основания; единая надбавка за сверхурочные становится оплатой первых
часов (100 + надбавка). Заявления на освобождения «на год» становятся заявлениями со сроком с / до, иждивенцы — строками;
заявления с «S» (отменено) помечаются «Проверить».
