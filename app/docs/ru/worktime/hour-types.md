# Виды часов, тарифы по должности и гарантированные часы

*Администрирование → Настройки → Виды часов.* Кроме стандартных часов по графику, в табеле есть **часы по видам**:
инструктаж, экзамены, полёты, резерв, простой, вождение… У каждого вида — **свой тариф за час** в трудовом отношении (по
должности) и, если это записано в договоре, **гарантированные часы в месяц**. Данные вносятся один раз — в приказе или в
карточке — и сами переходят в табель, расчёт зарплаты и отчёты.

## Для пользователя

**1. Оплата трудового отношения** (карточка → *Трудовые отношения*, по каждому отношению). В заголовке коротко: «Основное:
Пилот — оклад + тарифы: ZBOR, INSTR», «Совмещение: Пилот-инструктор — 30 %», «Внутреннее совместительство: Экзаменатор —
почасовой тариф». Ниже:
- **способ оплаты** (с историей «с даты», как оклад):
  - *Оклад* — оклад пропорционально отработанным часам;
  - *Почасовой тариф* — тариф × все отработанные часы (сверхурочные и праздничные — надбавка сверх простого часа);
  - *По видам часов* — без оклада: только часы по видам × их тарифы;
  - *Смешанный* — оклад плюс тарифы по видам часов;
- **тарифы по видам часов**: вид, лей в час, гарантированные часы в месяц (могут отсутствовать), с / по, источник (приказ);
- **дополнительные функции в рамках того же договора** — совмещение, замещение, временное исполнение (см. ниже).

Тарифы оплачиваются только при способах *По видам часов* и *Смешанный*; при остальных программа их не принимает (и не даёт
сменить способ, пока тарифы действуют — прекратите их в том же приказе).

**2. Приказ.** В приказах о приёме, об изменении оклада / условий и о совместительстве отдельным отношением есть поля *Способ
оплаты*, *Часовой тариф* и таблица **«Тарифы по видам часов»**: *добавить* / *изменить* / *прекратить*, вид, тариф,
гарантированные часы, с (пусто — дата приказа) / по, основание. При приёме таблица заполняется из **типовых тарифов
должности** (классификатор должностей, кнопка с кошельком). При подписании строки переходят в трудовое отношение, отмена
приказа их убирает.

**3. Табель.** У табеля есть колонки для видов часов с тарифом в отношениях табеля, для уже внесённых видов и для видов с
отметкой «Колонка для всех». Стандартные часы приходят из графика, как раньше; **часы по видам** вносятся:
- вручную — щелчок по ячейке: *по дням* (если вид позволяет) или *итого за месяц*; «Убрать часы» их удаляет;
- из **Excel** — кнопка «Часы по видам из Excel»: табельный номер, трудовое отношение (только если у сотрудника несколько в
  табеле: должность, «Внутреннее совместительство» или номер отношения), код вида, день (пусто — за месяц), часы; сначала
  проверка (видны строки с ошибками), затем импорт.

Ячейка показывает фактические часы, ниже — гарантию: «гар. 40,91» или, если гарантия больше фактических, «→ 40,91 (гар.)».
Наведите мышь — **гарантировано / доступные дни / фактически / к оплате** и объяснение. Часы по видам сохраняются при
«Пересчитать» и «Пересчитать всё». Печать и выгрузка в Excel содержат колонки видов (фактические, гарантированные, к оплате) и
лист «Ore pe tipuri» по дням.

**4. Гарантированные часы — минимум к оплате.** Оплачивается **max(фактические часы, гарантированные)**:
- гарантия 50, фактически 34 → оплачивается **50**;
- гарантия 50, фактически 54 → оплачивается **54**.

Гарантия месяца **уменьшается пропорционально** рабочим дням (производственный календарь), когда отношение «недоступно»:
- дни, когда отношения ещё нет или оно прекращено (приём / увольнение в середине месяца), и дни, когда тариф не действует;
- дни **отсутствия** из настройки — по умолчанию ежегодный отпуск (оплачивается по среднему, в котором часы уже учтены),
  дополнительный, без сохранения, учебный, оплачиваемые свободные дни, болезнь, декрет / отцовский, уход за ребёнком;
- дни **приостановления** договора.

**Командировка и обучение гарантию не уменьшают** — это работа. Примеры (22 рабочих дня, гарантия 50):
- принят 11 числа (15 рабочих дней из 22): 50 × 15 / 22 = **34,09**; фактически 20 → оплачивается 34,09;
- 5 дней ежегодного отпуска: 50 × 17 / 22 = **38,64**; фактически 30 → 38,64; командировка 5 дней — без уменьшения.

Объяснение в расчёте показывает всё: «ZBOR: garantat 50 × 17 / 22 zile disponibile (5 zile C) = 38,64; efectiv 30 → plătit
38,64 × 300 lei = 11 592 lei». Если тариф изменился в месяце, часы по дням идут по тарифу своего дня, итог за месяц делится
между тарифами по их дням; гарантия каждого тарифа считается по его дням.

**5. Расчёт зарплаты.** Автоматический вид расчёта **«Часы по видам»** (ORE): строка по каждому виду часов с тарифом —
оплачиваемые часы × тариф, с объяснением гарантии. Вид часов может иметь свой вид расчёта (в классификаторе: *Оплачивается
видом расчёта* — автоматический «Часы по видам», например «Оплата лётных часов» со своим счётом). Оплата по часам входит в
средний заработок для отпуска и больничного по отметке «Входит в средний» вида расчёта (ORE — да) и в доплату до
минимальной зарплаты (это тарифная оплата отработанного времени, не надбавка).

**Что входит в отработанные часы** (колонка *Связь с отработанными часами*):
- *Часть рабочего времени* (по умолчанию; инструктаж, экзамены, полёты в рабочее время) — часы уже в стандартных часах по
  графику: не суммируются повторно, не дают сверхурочных, не меняют долю нормы; если их больше отработанных часов строки,
  табель предупреждает;
- *Добавляются к отработанным* — рабочее время сверх стандартных часов: входит в отработанные часы (`OreLucrate`) и в долю
  нормы (и в минимальную базу CAS); сверхурочные из них сами не считаются — их вносят в ячейку дня;
- *Не рабочее время* (резерв дома, готовность) — только оплачивается тариф.

Часы по видам **не входят в часовой тариф** для ночных, праздничных и сверхурочных: они считаются по стандартным часам табеля.
Свои надбавки на лётные часы (ночь, праздники) — формулой (ниже); правила авиации — в следующем этапе.

**6. Формулы.** В формуле вида расчёта: `Ore.COD` — фактические часы из табеля, `OrePlatite.COD` — max(фактические;
гарантированные с уменьшением), `Garantat.COD` — уменьшенная гарантия месяца (0 без гарантии), `Tarif.COD` — тариф,
действующий на конец месяца. Например `OrePlatite.ZBOR * Tarif.ZBOR * 0,1` или `Ore.INSTR * 20`. Несуществующий код вида
часов — ошибка при сохранении. В редакторе: выберите вид часов и щёлкните по переменной.

## Совместительство ≠ совмещение

- **Совместительство** (внутреннее / внешнее, ТК — глава «Работа по совместительству», ст. 267 и след.; нумерацию проверить в
  действующей редакции) — **отдельное трудовое отношение**: договор, ставка, свой оклад или тарифы, свой табель, своя строка в
  расчёте.
- **Совмещение должностей (профессий), замещение временно отсутствующего и временное исполнение обязанностей** в рамках
  того же договора, без освобождения от основной работы (**ТК ст. 156**), — **не** отдельные отношения: это записи в основном
  трудовом отношении со своей доплатой: **% от своего оклада**, **% от оклада совмещаемой / замещаемой должности**,
  **фиксированная сумма в месяц** или **почасово по тарифу** (часы вида часов из табеля). Вид расчёта — **«Доплата за
  совмещение / замещение»** (CUMUL): % × оклад × отработанная доля × рабочие дни совмещения / дни отношения в месяце.

В приказах *Совмещение*, *Временное замещение*, *Временное исполнение* есть поле **«Как выполняется»**:
- *В рамках того же договора (ТК ст. 156)* — по умолчанию: запись в основном отношении; *«Досрочно прекращает»* — приказ
  заканчивает существующее совмещение на указанную дату;
- *Отдельное трудовое отношение* — когда человек выполняет работу другого **со своим табелем** (вне основного времени или на
  вакантной должности, по срочному договору): новое отношение со ставкой, окладом / тарифами и табелем, как совместительство.

Почему так: клиент хочет «способ оплаты и оклад для каждой должности независимо от того, как она оформлена» — запись в
основном отношении даёт каждой функции её оплату без фиктивного отношения (без двойной ставки в штатном расписании, без
повторного оклада), а работа со своим табелем остаётся отдельным отношением. Прекращение основного или замещаемого отношения
заканчивает совмещение; отмена приказа его убирает или восстанавливает.

## Для настройщика

- *Настройки → Виды часов*: код (латиница, цифры, «_» — в формулах `Ore.COD`), названия RO / RU / EN, группа, связь с
  отработанными часами, *Вносятся* (по дням или только итог за месяц), профиль, *Колонка для всех*, вид расчёта оплаты.
  Поставляются INSTR, EXAM; виды авиации, завода и транспорта приходят с их профилями; свои (например ZBOR) добавляются здесь.
- *Настройки → Должности (CORM)*, кнопка с кошельком: **типовые тарифы по видам часов** должности.
- *Настройки → Отдых между сменами и ночные смены в месяц*: **отсутствия, уменьшающие гарантированные часы**, и отметка для
  приостановления.
- Старые данные: «Доплата за совмещение (%)» в отношении сама перенесена в записи совмещения («% от своего оклада», по
  периодам из истории), суммы те же; вид CUMUL переименован.
