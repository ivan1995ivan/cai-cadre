# Сроки и оповещения

Список «к исполнению» для отдела кадров, бухгалтерии и заведующих отделениями. Формируется каждый день по данным
программы: карточкам сотрудников, приказам, отпускам, графикам. Каждый видит только те оповещения, которые его касаются:

- **Кадры** — все кадровые сроки по всем отделениям;
- **Бухгалтерия** — то, что влияет на зарплату (приказы, окончание социальных отпусков, ступени стажа, IRM19);
- **Заведующий отделением** — сроки сотрудников своих отделений, заявления на отпуск, графики.

Администратор видит все оповещения.

## Вкладка «К исполнению»

Колонки: **срок**, сколько осталось (*через 5 дней*, *сегодня*, *3 дня назад* — срок просрочен, красным), **вид** и **что
сделать**. Клик по тексту (или двойной клик по строке) открывает карточку сотрудника на нужной вкладке, приказ, график или
отчёт. Фильтр сверху показывает только один вид; кнопка Excel выгружает список.

| Вид | Когда появляется |
|---|---|
| Окончание испытательного срока | За 10 дней до даты из карточки (трудовые отношения) |
| Истечение срочного договора | За 30 дней до даты окончания срочного индивидуального трудового договора |
| Истечение удостоверения личности | За 30 дней |
| Истечение категории / сертификата | За 180 дней (квалификационная категория, сертификаты) |
| Окончание отпуска по уходу за ребёнком | За 30 дней — подготовьте приказ о возобновлении работы |
| Окончание отпуска по беременности и родам | За 14 дней |
| Неиспользованный отпуск (ст. 118 ТК) | У сотрудника есть неиспользованные дни за завершённые рабочие годы |
| Истечение дисциплинарного взыскания | За 7 дней до погашения взыскания |
| Достижение пенсионного возраста | За 180 дней (возраст — в настройке оповещений) |
| Дни рождения и юбилеи | За 7 дней; юбилеи (50, 60 … лет) отмечены |
| Переход на новую ступень стажа | За 30 дней — меняется надбавка за стаж |
| Приказ без ознакомления | Приказ подписан 3 дня назад, а сотрудник не расписался об ознакомлении |
| Приказы для бухгалтерии | Приказы, подписанные за последние 7 дней, которые меняют зарплату |
| Заявления на отпуск к рассмотрению | Новые заявления |
| Отпуска следующего месяца | Кто уходит в отпуск в следующем месяце |
| Нет графика на следующий месяц | После 20-го числа, если у отделения нет графика работы на следующий месяц |
| Срок IRM19 | За 5 рабочих дней до срока подачи |

## Что отслеживается (администратор)

Настройка — в *Администрирование → Настройки → Сроки и оповещения: что отслеживается*.

Для каждого вида: **включено / выключено** и **за сколько дней** до срока появляется оповещение. Колонка «Кто получает»
показывает, кому оно отправляется. Ниже: **пенсионный возраст** (мужчины / женщины) и **сводка по почте**.

**Отправить уведомления сейчас** — сразу отправляет то, что обычно отправляется ночью.

## Уведомления

Каждую ночь программа отправляет уведомления (колокольчик в шапке) о новых оповещениях, **один раз** на каждый срок. Если
сводка по почте включена, те, у кого в профиле указан адрес e-mail, получают ещё и письмо со списком новых оповещений.

## Почта (администратор)

Настройка — в *Администрирование → Настройки → Почта (e-mail) для уведомлений и расчётных листков*.

Почтовый сервер учреждения: SMTP-сервер, порт (587 с TLS или 465 с SSL), пользователь, пароль и адрес отправителя.
Пароль хранится в зашифрованном виде. **Отправить проверку** проверяет настройки — укажите адрес и проверьте почтовый
ящик.
