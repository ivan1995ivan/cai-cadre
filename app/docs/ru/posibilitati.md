# Возможности системы

**CAI CADRE** — кадровый учёт и зарплата для публичных медико-санитарных учреждений (IMSP): штатное расписание, личные дела,
приказы, отпуска, рабочее время, зарплата, обучение, охрана здоровья, воинский учёт, отчёты и личный кабинет сотрудника —
на выбранных языках (румынский, русский, английский), на компьютере и на телефоне.

## Учреждение и штатное расписание
- **Подразделения** (департаменты, отделы, цеха, филиалы, склады) с вредными условиями и днями дополнительного отпуска.
- **Штатное расписание** с версиями, датой вступления в силу, утверждением, должностями с **кодом CORM 006-2021**, дробными
  единицами, предельной численностью по категориям персонала (группы CORM, редактируемый классификатор); печать с Государственным гербом.
- **Замещение должностей**: утверждено / занято / временно вакантно / вакантно.
- **Классификаторы**: должности, специальности, правовые основания, виды приказов, квалификационные категории, документы,
  вакцины и другие; у каждого поля — кнопка **«…»**, открывающая классификатор.

## Сотрудники
- **Электронное личное дело** (карточка MR-2): личные данные, документы со сроками, семья, образование, квалификационная
  категория, стаж (общий, в здравоохранении, по специальности, в учреждении), воинский учёт, здоровье, чек-лист при приёме
  и увольнении, журнал доступа к персональным данным.
- **Несколько трудовых отношений** у сотрудника: основное, внутреннее и внешнее совместительство, замещение, резидентура,
  договор оказания услуг — у каждого своя ставка в процентах и своя история.
- Печать: карточка MR-2, справки с места работы и о стаже; **импорт из Excel**.

## Приказы
- Все кадровые приказы (приём, перевод, совместительство, замещение, отпуска, командировки, премии, взыскания,
  приостановление, увольнение, аттестация, штатное расписание…), индивидуальные и коллективные, с правовым основанием,
  нумерацией по журналам и **действием при подписании** в личном деле; отмена приказом; журнал приказов.

## Отпуска и рабочее время
- **Остатки отпусков** по рабочим годам (основной + дополнительный), **годовой график**, **заявления на отпуск**
  (утверждает заведующий отделением, по ним формируются приказы), социальные отпуска, **больничные листы** с днями работодателя.
- **Графики работы** и смены, **график смен** с проверками по ТК ст. 101, **табель** по образцу Коллективной конвенции
  № 17/2020, с ночными, праздничными и сверхурочными часами;
  производственный календарь.

## Зарплата (дополнительный модуль)
- Константы с историей, гибкие **виды расчёта**, заявление о льготах, **месячный расчёт** по каждому трудовому отношению
  (табель, надбавки, совместительство, ночные, праздничные, отпуска по среднему, больничные, премии, CNAM, подоходный налог, CAS),
  **выплата** (аванс, зарплата, карта / наличные, файл для банка), годовая личная карточка.
- **IPC21**, **IALS21**, **IRM19** — Excel и **XML по схеме ГНС**.

## Обучение, здоровье, воинский учёт
- **Реестр НМО**, кредиты за аттестационный период, **календарь аттестации**, приказ о присвоении категории,
  **годовой план обучения**.
- **Медосмотры**, **прививки**, **инструктажи по охране труда** со сроками и приказом о направлении на медосмотр.
- **Воинский учёт**: реестр призывников и военнообязанных, изменения за месяц для военкомата, список призывников.

## Сроки, отчёты, кабинет
- **Сроки и оповещения**: испытательный срок, срочные договоры, документы, категории, социальные отпуска, неиспользованный
  отпуск, взыскания, пенсионный возраст, юбилеи, стаж, приказы, IRM19, медосмотры, кредиты НМО — уведомление в системе и
  **сводка по почте**.
- **Стартовая панель** с показателями дня; **каталог отчётов** (движение кадров, структура персонала, вакансии, отпуска,
  сводный табель, медицинские кадры МЗ № 17, Труд 1 НБС и другие) с Excel и печатью.
- **Личный кабинет сотрудника**: свои данные, остаток отпуска, приказы с «ознакомлен(а)», заявления (отпуск, справки),
  расчётные листки.

## Администрирование
- **Роли и права** (начальник отдела кадров, инспектор, директор, заведующий отделением, бухгалтерия, сотрудник), видимость
  по подразделениям, скрытие чувствительных полей по роли; журнал аудита; **редактируемые печатные формы**.
- Языки системы, тема, меню как в 1С, все настройки в одном месте (Администрирование → Настройки, с поиском); резервные копии и обновления из программы.
- Установка на сервер учреждения (Windows, Python в комплекте) или в Docker; SQLite, PostgreSQL, MySQL, MS SQL, Oracle.
- Лицензия по числу пользователей; модуль **Зарплата** лицензируется отдельно.
