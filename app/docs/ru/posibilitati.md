# Возможности системы

**CAI CADRE** — кадровый учёт и зарплата для частных предприятий Республики Молдова (SRL, SA, ÎI): штатное расписание, личные дела,
приказы, отпуска, рабочее время, зарплата, обучение персонала, охрана здоровья и труда, воинский учёт (дополнительный модуль),
отчёты и личный кабинет сотрудника — на выбранных языках (румынский, русский, английский), на компьютере и на телефоне.

## Предприятие и штатное расписание
- **Подразделения** (департаменты, отделы, цеха, филиалы, склады) с вредными условиями и днями дополнительного отпуска.
- **Штатное расписание** с версиями, датой вступления в силу, утверждением, должностями с **кодом CORM 006-2021**, дробными
  единицами, предельной численностью по категориям персонала (группы CORM, редактируемый классификатор); печать с шапкой предприятия.
- **Замещение должностей**: утверждено / занято / временно вакантно / вакантно.
- **Классификаторы**: должности, специальности, правовые основания, виды приказов, образование, документы и другие; у каждого поля — кнопка **«…»**, открывающая классификатор.

## Сотрудники
- **Электронное личное дело**: личные данные, документы со сроками, семья, образование и обучение, стаж (общий, по
  специальности, на предприятии), здоровье и охрана труда, воинский учёт (с включённым модулем), чек-лист при приёме и
  увольнении, журнал доступа к персональным данным.
- **Несколько трудовых отношений** у сотрудника: основное, внутреннее и внешнее совместительство, замещение,
  договор оказания услуг — у каждого своя ставка в процентах и своя история.
- Печать: карточка MR-2, справки с места работы и о стаже; **импорт из Excel**.

## Приказы
- Все кадровые приказы (приём, перевод, совместительство, замещение, отпуска, командировки, премии, взыскания,
  приостановление, увольнение, направление на повышение квалификации, штатное расписание…), индивидуальные и коллективные, с правовым основанием,
  нумерацией по журналам и **действием при подписании** в личном деле; отмена приказом; журнал приказов.

## Отпуска и рабочее время
- **Остатки отпусков** по рабочим годам (основной + дополнительный), **годовой график**, **заявления на отпуск**
  (утверждает руководитель подразделения, по ним формируются приказы), социальные отпуска, **больничные листы** с днями работодателя.
- **Графики работы** и смены, **график смен** с проверками по ТК ст. 101, **табель** по образцу Коллективной конвенции
  № 17/2020, с ночными, праздничными и сверхурочными часами;
  производственный календарь.

## Зарплата (дополнительный модуль)
- Константы с историей, гибкие **виды расчёта**, заявление о льготах, **месячный расчёт** по каждому трудовому отношению
  (табель, надбавки, совместительство, ночные, праздничные, отпуска по среднему, больничные, премии, CNAM, подоходный налог, CAS),
  **выплата** (аванс, зарплата, карта / наличные, файл для банка), годовая личная карточка.
- **IPC21**, **IALS21**, **IRM19** — Excel и **XML по схеме ГНС**.

## Обучение, охрана здоровья и труда, воинский учёт
- **Реестр обучения**: курсы, инструктажи, сертификаты со сроком действия и оповещением об истечении; **годовой план
  обучения** по истекающим сертификатам.
- **Медосмотры** (при приёме, периодические — с периодичностью по должности / подразделению, ПП 1025/2016) и **инструктажи
  по охране труда** (Закон 186/2008) со сроками и приказом о направлении на медосмотр.
- **Воинский учёт** — дополнительный модуль, по умолчанию выключен (больше не обязателен, Закон 112/2023): реестр
  призывников и военнообязанных, изменения за месяц для военкомата, список призывников.

## Сроки, отчёты, кабинет
- **Сроки и оповещения**: испытательный срок, срочные договоры, документы, сертификаты обучения, социальные отпуска,
  неиспользованный отпуск, взыскания, пенсионный возраст, юбилеи, приказы, IRM19, медосмотры, инструктажи — уведомление в
  системе и **сводка по почте**.
- **Стартовая панель** с показателями дня; **каталог отчётов** (движение кадров, структура персонала, вакансии, отпуска,
  сводный табель, Труд 1 НБС и другие) с Excel и печатью.
- **Личный кабинет сотрудника**: свои данные, остаток отпуска, приказы с «ознакомлен(а)», заявления (отпуск, справки),
  расчётные листки.

## Администрирование
- **Роли и права** (начальник отдела кадров, инспектор, директор / администратор, руководитель подразделения, бухгалтерия,
  сотрудник), видимость по подразделениям, скрытие чувствительных полей по роли; журнал аудита; **редактируемые печатные формы**.
- Языки системы, тема, меню как в 1С, все настройки в одном месте (Администрирование → Настройки, с поиском); резервные копии и обновления из программы.
- Установка на сервер предприятия (Windows, Python в комплекте) или в Docker; SQLite, PostgreSQL, MySQL, MS SQL, Oracle.
- Лицензия по числу пользователей; модуль **Зарплата** лицензируется отдельно.
