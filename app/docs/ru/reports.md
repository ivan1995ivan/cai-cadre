# Отчёты

Каталог отчётов по группам: **Персонал**, **Отпуска и рабочее время**, **Приказы**, **Внешняя отчётность**. Клик по
карточке открывает отчёт. Карточки с пометкой *в модуле* ведут на страницу модуля, где отчёт уже есть (список
сотрудников, замещение штатных единиц, журнал приказов, остатки отпусков, табель, IPC21 / IALS21 / IRM19).

**Поиск** (вверху справа): ищет по названию, описанию и группе отчёта, без диакритики («pontaj», «отпуск»); **Enter**
открывает отчёт, когда остался один.

## Как работать с отчётом

1. Выберите фильтры вверху — у каждого отчёта свои: **период**, **на дату**, **месяц** или **год**, **подразделение**
   (с вложенными подразделениями), **категория персонала**, **только основные должности** или *также совместительство /
   замещение*, **вид отсутствия**. Отчёт пересчитывается сразу.
2. Вверху показаны краткие показатели (например, численность на начало и на конец), ниже — таблица с разделами и итогом.
3. **Excel** выгружает ровно то, что вы видите (право *Отчёты → Экспорт*). **Печать** — с гербом, шапкой учреждения и
   подписью (форма «Отчёт» в *Администрирование → Настройки → Печатные формы*).

Заведующий отделением видит в отчётах только свои отделения.

## Отчёты

| Отчёт | Что показывает |
|---|---|
| **Движение кадров** | Принятые, уволенные (с причиной) и переведённые за период; численность на начало и на конец; **коэффициент текучести** = уволенные / среднесписочная численность × 100 |
| **Структура персонала** | На дату: по категориям персонала, полу, возрастным группам, образованию (высшему из имеющихся), квалификационной категории, общему стажу, ставке; с *также совместительство* — и по виду трудовых отношений |
| **Трудовой стаж** | По каждому сотруднику: общий, в системе здравоохранения, по специальности, в учреждении |
| **Дни рождения и юбилеи** | У кого день рождения в периоде и сколько исполняется лет; юбилеи отмечены |
| **Выход на пенсию** | Кто достигает пенсионного возраста в выбранном году (возраст меняется в *Администрирование → Настройки → Сроки и оповещения: что отслеживается*) |
| **Вакантные должности** | Вакантные единицы в действующем штатном расписании — для объявлений, НАЗН (ANOFM) и сайта |
| **Отпуска и отсутствия за период** | Отпуска, командировки, больничные листы, попадающие в период: даты и дни в пределах периода; итог по видам |
| **Сводный табель** | Итоги табелей месяца по подразделениям: отработанные дни и часы, ночные, праздничные, сверх / ниже нормы, отсутствия по кодам |
| **Выписка из приказов для бухгалтерии** | Пункты приказов, подписанных за период, которые меняют зарплату, с их текстом |
| **Приказы по видам** | Сколько подписанных приказов и пунктов по каждому виду |
| **Медицинские кадры (МЗ, № 17)** | По медицинским должностям: утверждённые / занятые единицы, основные работники, внутреннее / внешнее совместительство, женщины, квалификационные категории, пенсионный возраст |
| **Труд 1 (НБС)** | Численность на конец месяца (и женщин), среднесписочная численность (без отпусков по беременности и родам и по уходу за ребёнком), внешние совместители, приём, увольнение, вакантные единицы, отработанные часы, фонд оплаты труда из утверждённых расчётов |

> Отчёты для статистики (МЗ № 17, Труд 1) дают основные цифры; сама форма заполняется на сайте учреждения, которое её
> запрашивает. Обучение, аттестация, охрана здоровья и воинский учёт — в своих группах каталога.
