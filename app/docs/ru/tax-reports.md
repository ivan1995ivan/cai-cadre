# Отчётность (IPC21, IALS21, IRM19)

Отчёты формируются из **выплаченных ведомостей** (выплаченный доход и удержанные налоги: IPC21 таблица 1, IALS21), из
**утверждённых расчётов** (база НКСС: IPC21 таблица 2) и из **подписанных приказов** (IRM19). У каждого есть
предварительный просмотр на экране, **экспорт в Excel** (для проверки) и **XML-декларация** по официальной схеме
Государственной налоговой службы, готовая к загрузке в ГНС. Вверху показываются предупреждения: недостающие данные в
шапке, лица без ИДНП, должности без кода CORM.

**Данные плательщика** (один раз, при запуске; *Администрирование → Настройки → Налоговая отчётность: данные плательщика*): код плательщика НКСС, код подразделения ГНС, CUATM (4 знака), CAEM (как правило
8610), контактные e-mail и телефон. Наименование, IDNO, директор и главный бухгалтер берутся из Констант.

**IPC21** (ежемесячно, до 25-го числа следующего месяца):
- таблица 1: код 11 «SAL» — доход, выплаченный в месяце, удержанные налог и взносы НКМС (из ведомостей, выплаченных в
  месяце, по дате выплаты); код 61 — итог; контрольная сумма;
- приложение к таблице 1: налог с зарплаты по CUATM;
- таблица 2, по каждому лицу и категории (классификатор НКСС): **101** ИТД (включая внутреннее совместительство), **123**
  внешнее совместительство, **105** гражданско-правовой договор (оказание услуг), **160** ежегодный отпуск (с отпускными),
  **16011** учебный отпуск, **16012** дополнительный отпуск, **159** отпуск без сохранения зарплаты, **157 / 158** уход за
  ребёнком, **165** отцовский отпуск, **15311** пособие по болезни за счёт работодателя; период, тариф (24 %), код
  должности (CORM — обязательно), база расчёта, пособие, взнос НКСС;
- строка 1.1 b) «по тарифу 24 %» (медико-санитарные учреждения).

**IALS21** (ежегодно, до 25 января): по лицам — ИДНП, ИДНП супруга / супруги (если есть льгота Sm), код источника
(SAL), доход, выплаченный за год (из выплаченных ведомостей), льготы по кодам **P** (личная), **M** (повышенная), **Sm** (на супруга / супругу), **N** (на
иждивенцев), **H** (на иждивенцев с инвалидностью), НКМС и налог; контрольная сумма = итог налога; приложение с ИДНП
иждивенцев. Льготы распределяются по кодам согласно заявлению сотрудника о льготах (вкладка «Зарплата»).

**IRM19** (в течение 10 рабочих дней с даты приказа): кол. 8 — **01** приём на неопределённый срок, **05** на
определённый срок, **02** прекращение, **03** приостановление, **04** снятие приостановления; кол. 9 — причина
увольнения (**114** по собственному желанию, **113** сокращение, **115** прекращение ИТД, **116** иные основания; можно
изменить для каждой причины в *Администрирование → Настройки → Причины прекращения договора*, поле «irm19»); кол. 5–7 — **157** / **158** уход за ребёнком, **165**
отцовский отпуск, с периодом. Просроченный срок выделяется красным.

Права: «Налоговая отчётность» — просмотр и экспорт (у бухгалтерии есть всё; у инспектора отдела кадров нет).
