# Населённые пункты

Классификатор населённых пунктов Молдовы и Румынии.

## Официальные списки
- **Молдова** — CUATM (Национальное бюро статистики), с названиями на русском, районом и коммуной;
- **Румыния** — SIRUTA (INS, data.gov.ro), с коммуной, уездом и почтовым индексом.

Отметьте страны, населённые пункты которых используете, и нажмите **Загрузить / обновить**. Снятая галочка =
населённые пункты страны убираются из классификатора (добавленные вручную остаются).

## Поиск и новый населённый пункт
Поиск идёт по населённому пункту, коммуне, району / уезду и почтовому индексу; города показываются раньше сёл.
**Новый населённый пункт** — для других стран или отсутствующего пункта: страна, название (и на русском), тип,
коммуна, район / уезд, почтовый индекс. Добавленные вручную помечены «вручную».
