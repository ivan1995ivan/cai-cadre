# Нумерация документов

У каждого типа документа своя серия, например **AD-2026-00001** (Справка), **CS-2026-00001** (Расчёт зарплаты).
Щелчок по строке открывает настройки серии.

- **Префикс**: буквы в начале.
- **С годом**: год в номере.
- **С 1 каждый год**: 1 января нумерация начинается заново.
- **Количество цифр**: 00001 = 5 цифр.
- **Следующее значение**: например, чтобы продолжить нумерацию из 1С. **Не уменьшайте** его ниже уже использованных номеров.

Колонка **Следующий номер** показывает, как будет выглядеть следующий номер.

Приказы нумеруются не здесь: номер они получают при подписании, в своём журнале (см. [Приказы](help:orders)).

Номера гарантированно уникальны, даже если несколько пользователей создают документы в одну и ту же секунду.
