# Печатные формы

Здесь администратор меняет вид печатных документов: приказ и выписка из приказа, журнал приказов, штатное расписание,
личная карточка (MR-2), справки, список сотрудников, график отпусков, табель учёта рабочего времени, график
смен, расчётная и платёжная ведомости, расчётный листок, список для банка, личная карточка учёта доходов за год,
отчёты.

## Как работать
1. Выберите тип документа и шаблон.
2. Вкладка **Просто**: размер шрифта, **С логотипом фирмы** и, у некоторых форм, **Тексты бланка** (на RO и RU,
   пусто = текст по умолчанию). Логотип, печать и подпись загружаются в *Константы → Логотип и печать*.
3. Для более серьёзных изменений: **HTML** (структура) и **CSS** (оформление). Справа сразу виден
   **предпросмотр на реальных данных**, на RO или RU.
4. **Сохранить**.

Там же вверху: **По умолчанию** (форма, предлагаемая при печати), **Активен**, ориентация (**Книжная** / **Альбомная**).

## Шапка и подписи
Все формы начинаются с `{% company_header %}` — шапки предприятия из *Констант*: логотип, наименование с правовой
формой, IDNO, CAEM, адрес, телефон, e-mail, сайт и банковский счёт по умолчанию (только заполненное). Подписи внизу берут
имена и должности из *Константы → Подписи на формах* (руководитель, главный бухгалтер, ответственный за кадры). В
**Текстах бланка** можно использовать в фигурных скобках данные предприятия: `{întreprinderea}`, `{conducătorul}`,
`{funcția_conducătorului}`, `{contabilul}`, `{funcția_contabilului}`, `{resurse_umane}`, `{funcția_resurse_umane}`
(полный список — под заголовком «Тексты бланка»). Например, отметка «Утверждаю» в графике отпусков по умолчанию —
`УТВЕРЖДАЮ` / `{funcția_conducătorului} ______ {conducătorul}`.

## Переменные
Значения подставляются через `{{ переменная }}`, например `{{ company.full_name }}`, `{{ company.director_position }}`,
`{{ emp.full_name }}`; список данных предприятия — в «Доступных переменных» под редактором.
Условия: `{% if options.show_idnp %} ... {% endif %}`. Повторение: `{% for ... %} ... {% endfor %}`.
Формат денег: `{{ значение|money }}` → 1 234,50.

## Параметры
Галочки (например, с фотографией, с окладом, с IDNP) — это значения **по умолчанию**, предлагаемые при печати;
пользователь может изменить их в окне печати.

## Безопасность
- **Восстановить оригинал**: встроенные шаблоны в любой момент возвращаются к исходному виду.
- **Копия**: сделайте свой вариант, а оригинал оставьте нетронутым.
- Шаблон получает только данные документа; он не может прочитать пароли или другие данные системы и не может запускать скрипты.
