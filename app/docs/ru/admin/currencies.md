# Валюты

## Валюты
MDL — базовая валюта. EUR, USD, RON, UAH добавлены при установке. Можно добавить другие (трёхбуквенный код,
наименование, символ).
**Автоматический курс НБМ**: курс загружается с сайта Национального банка Молдовы.

## Загрузка курса НБМ
Выберите дату и нажмите **Загрузить курс НБМ**. Сохраняются курсы всех валют с «автоматическим курсом».
Если на какой-то день курса нет (выходной), система берёт **последний известный курс** до этой даты.

## Курс вручную
Для валют без курса НБМ или для исправлений: валюта, дата, курс в MDL и за сколько единиц. Помечается источником
«MANUAL».

## Ставки НДС
20%, 8%, 0% и «Scutit» (освобождение от НДС) добавлены при установке; одна отмечается **по умолчанию**.
