# Импорт из Excel

Запуск новой базы без 1С. Шаги выполняются по порядку, потому что каждый файл опирается на предыдущие:
должности (CORM) → специальности → подразделения → сотрудники с трудовыми отношениями → документы, семья, образование,
квалификационные категории, предыдущий стаж. Видны только шаги, на которые у вас есть права.

Для каждого шага: **Скачать шаблон**, заполните его (шапку не меняйте, порядок колонок не важен, колонки со * обязательны),
загрузите. Система сначала выполняет **проверку**: показывает, сколько строк будет добавлено, сколько обновлено, и
ошибки по строкам. Ничего не записывается, пока не нажмёте **Импортировать**; если в какой-либо строке ошибка, из файла
не записывается ничего.

Сотрудники: строка = человек и одни трудовые отношения. Для внутреннего совместительства повторите человека в другой
строке. Существующий сотрудник узнаётся по IDNP, затем по табельному номеру, поэтому исправленный файл можно
импортировать повторно. Галочка **Создать в классификаторе недостающие должности (по наименованию)** добавляет
не найденные в классификаторе должности.

Строки штатного расписания импортируются из карточки штатного расписания (*Учреждение → Штатное расписание → Импорт
строк из Excel*).
