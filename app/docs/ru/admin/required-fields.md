# Обязательные поля

Страница для отметки полей, которые должны быть заполнены, с пометкой момента проверки: **при сохранении** или
**при проведении**.

В текущей версии ещё нет кадровых форм (сотрудники, договоры, приказы, отпуска) с обязательными полями, выбираемыми
здесь: обязательные поля этих форм задаются программой.

**Сохранить** (активна после изменения) применяет галочки для всех пользователей. Галочки меняет только тот, у кого есть
право на настройки.
