# Главное меню

Разделы меню и в каждом группы **Журналы** и **Отчёты**, как в 1С. Порядок один для всего учреждения; кто что видит,
решается в каждой роли. Настройки не стоят в разделах: все они в [Администрирование → Настройки](help:settings).

## Порядок по умолчанию
**Главное**, **Учреждение**, **Сотрудники**, **Приказы**, **Отпуска и рабочее время**, **Зарплата**,
**Обучение и учёт**, **Отчёты**, **Администрирование**. В каждом разделе:
- **Журналы** — документы раздела (сотрудники, приказы, отпуска, табель...);
- **Отчёты** — отчёты раздела, открываются сразу (например, у Сотрудников: движение кадров, стаж, выход на пенсию).

В **Администрировании**: Настройки, Кто онлайн, Импорт из Excel, Журнал аудита, резервные копии, удаление помеченных
объектов, лицензия.

Одна функция может стоять в нескольких местах (MUNCA-1 — в Зарплате и в Отчётах). Новые функции, появившиеся
в программе после сохранения меню, сами попадают в свою группу раздела по умолчанию.

Если учреждение работает без зарплаты (*Константы → Модули*), функции раздела **Зарплата** не показываются.

## Перемещение
В дереве перетаскивайте мышью:
- **функцию** в другую группу или раздел (брошенная на группу, она становится в ней первой; на раздел — первой в Журналах)
  или выше / ниже между функциями; она уходит только из той группы, откуда её взяли, в других местах остаётся;
- **раздел** выше или ниже, между другими разделами.

## Скрытые функции
В конце дерева стоят функции, которых нет нигде в меню. Перетащите их в группу, чтобы они появились. Функция, брошенная
в **Скрытые функции**, исчезает из группы, откуда её взяли; в программе она остаётся (избранное, адрес).

## Раздел
Щелчок по разделу в дереве → справа:
- название на **RO** и **RU** (пусто = стандартное название; поле RU видно, только если включён русский язык);
- значок;
- **Удалить раздел** — только пустой раздел: сначала перенесите функции в другие разделы.

**Новый раздел** добавляет раздел в конец; переименуйте его и перетащите в него функции.

## Сохранение
**Сохранить** (активна после изменения) сохраняет меню для всех. **Порядок по умолчанию** возвращает стандартное меню.
Страница открывается только тем, у кого есть право изменять константы и настройки.

## Сверху или слева
**Расположение меню для всех**:
- **сверху** — разделы сверху, а слева группы выбранного раздела;
- **слева** — всё меню слева деревом: разделы раскрываются щелчком, с группами и функциями.

Каждый пользователь может изменить расположение кнопкой с палитрой (справа вверху).

С включённой [Панелью функций](help:panel) (*Константы → Модули*) разделы стоят сверху вкладками, у каждого своя
панель, а выбор «сверху / слева» не показывается; порядок разделов и функций отсюда сохраняется.

## Открытые окна
Нижняя панель держит открытые страницы, как в 1С. **Закрыть все** закрывает их все, остаётся только Начальная страница.

## Кто что видит
В [Ролях](help:admin/roles), в каждой роли, блок **Главное меню**: галочки разделов и функций. Снята галочка =
не видно в меню; права роли не меняются. Функция из нескольких разделов скрывается, только если галочка снята везде.
Функция видна, только если у роли есть и право её открыть (отчёты воинского учёта — право на воинский учёт). Раздел без
видимых функций не показывается, пустая группа в меню не появляется.
