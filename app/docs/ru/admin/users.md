# Пользователи

Список людей, работающих в системе. Поиск по имени и фильтр по роли.

## Добавление пользователя
1. Нажмите **Добавить**.
2. Заполните фамилию, имя, отчество, **пользователя** (с ним входят в систему) и **пароль** (минимум 8 символов, не
   только цифры, не простой пароль).
3. При необходимости: e-mail, телефон, должность и **язык**, на котором он работает.
4. Выберите одну или несколько **ролей**. Права ролей суммируются.
5. Отметьте **«Сменить пароль при первом входе»**, если выдали временный пароль.
6. **Сохранить**.

При редактировании поле **Новый пароль** оставляют пустым, чтобы пароль не менялся.

## Подразделения пользователя (руководитель подразделения)
Поле **Его подразделения** связывает пользователя с подразделениями, которыми он руководит (руководитель подразделения,
его заместитель). Роли с видимостью «только мои» видят сотрудников, отпуска, графики, табель и отчёты только этих подразделений;
с «мои подразделения» — и вложенных. Без подразделений руководитель подразделения не видит ни одного сотрудника. В
списке колонка **Его подразделения** показывает, кто за какое подразделение отвечает.

## Учётная запись для кабинета сотрудника
Сотрудники, которые входят только в [Мой кабинет](help:portal), получают учётную запись из карточки сотрудника: кнопка
**Кабинет** создаёт пользователя с ролью «Сотрудник» и временным паролем. Учётные записи для всех сотрудников без
учётной записи создаются сразу из списка сотрудников (**Учётные записи для кабинета**).

## Отключение вместо удаления
Когда сотрудник уходит, **отключите его** (переключатель «Активен»). Его история (документы, журнал) остаётся привязанной к нему.
Удаление возможно, но не рекомендуется.

## Защита
- Нельзя отключить или удалить собственную учётную запись.
- Последний активный администратор не может потерять роль администратора.
- Количество активных пользователей ограничено лицензией.

## Забыт пароль администратора
На сервере, в папке программы (*C:\Program Files\CAI CADRE*), запустите **crm-admin.cmd** правой кнопкой →
*Run as administrator* и дважды введите новый пароль. Учётная запись **admin** получает новый пароль или создаётся, если
её нет. Для другого пользователя: `crm-admin.cmd имя` из Command Prompt, запущенной от имени администратора.
