# Журнал аудита

Кто, что и когда изменил в системе.

- **Создание / Изменение / Удаление**: для каждого изменения видно **старое значение → новое значение** (нажмите «+» слева от строки).
- **Вход / Неудачный вход**: входы в систему, с IP-адресом. Много неудачных входов подряд может означать попытку подбора пароля.

Фильтры: период, действие, объект (тип записи), поиск по названию.
Журнал нельзя изменить из интерфейса.
