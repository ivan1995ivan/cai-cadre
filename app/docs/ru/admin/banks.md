# Банки

Классификатор банков Молдовы и Румынии, с **BIC / SWIFT**, кодом в IBAN, IDNO / CUI, адресом и телефоном.
Из него выбирается банк в банковских счетах учреждения (*Константы → Банковские счета*).

## Официальные списки
Банки загружаются сами при установке:
- **Молдова** — лицензированные банки (НБМ), плюс Государственное казначейство и НБМ;
- **Румыния** — коды BIC (TransFond), CUI и адреса (реестр ASF), плюс объединённые банки — для старых IBAN
  (например, OTP Bank România → Banca Transilvania).

Отметьте используемые страны и нажмите **Загрузить / обновить**, чтобы получить список из новой версии программы.
Снятая галочка = банки страны убираются из классификатора. Банки, добавленные вручную, остаются всегда. Банковские счета
сохраняют записанный банк.

## Банк по IBAN
При вводе IBAN банк и BIC заполняются сами: по IBAN, из **Кода в IBAN** — идентификатора банка после контрольных цифр
(Молдова: 2 символа, AG = maib; Румыния: 4, BTRL = Banca Transilvania). Название, введённое вручную, не меняется.

Рядом с полем **Банк** кнопка **…** открывает список с поиском (название, BIC, IDNO); щелчок по строке = подставляются
название и BIC.

## Новый банк
**Новый банк** — для банка другой страны или отсутствующего в списке: страна, BIC / SWIFT, код в IBAN (чтобы банк
узнавался по IBAN), название, IDNO / CUI, адрес, контакты.
