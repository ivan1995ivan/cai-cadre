# Отпуска

**Остатки** показывают по каждому сотруднику текущий рабочий год, положенные дни, начисленные, использованные за год,
**остаток** (дни, начисленные на выбранную дату, минус использованные) и сколько можно **планировать** (с полным правом за
текущий рабочий год). Двойной клик по строке открывает вкладку «Отпуска» в карточке сотрудника. Список выгружается в Excel.

**Как рассчитывается право:**
- рабочий год начинается с даты приёма (основное место) и длится один год; отпуска по уходу за ребёнком (или другие
  периоды, выбранные в настройке *Учёт отпусков*) продлевают его на количество своих дней;
- дней в год = основные дни должности (по умолчанию 28) + дни за условия труда (наибольшее значение из должности и
  подразделения — ПП 1223/2004) + **личные права** из карточки сотрудника (дети, инвалидность, коллективный договор,
  стаж);
- за текущий год дни начисляются пропорционально; при увольнении — тоже пропорционально, до даты увольнения;
- использованное берётся из приказов о ежегодном и дополнительном отпуске: если в приказе указан рабочий год — за этот
  год; если нет — за самый ранний год с оставшимися днями. Отзыв из отпуска возвращает неиспользованные дни;
- **компенсация** деньгами (приказ «Компенсация неиспользованного отпуска» или компенсированные дни из приказа об
  увольнении) уменьшает остаток.

**Заявления на отпуск:** подаёт сотрудник из [личного кабинета](help:portal) или
регистрируют отдел кадров либо заведующий отделением. Заведующий отделением **согласовывает** или **отклоняет** (с причиной). Из согласованных заявлений отдел кадров
отмечает строки и нажимает **«Сделать приказы»**: создаётся по одному сводному приказу на каждый вид отпуска (черновик,
с заявлениями в качестве основания), который подписывается как любой приказ.

**Настройка** *Администрирование → Настройки → Учёт отпусков* (администратор): **дата начала учёта** — рабочие годы, закончившиеся раньше, не рассчитываются, их остаток
вносится в карточку сотрудника как «начальный остаток»; периоды, которые не дают права на отпуск.

**Начальный остаток** при переходе на программу: в карточке сотрудника → Отпуска → Корректировки остатка → Добавить, вид
«Начальный остаток», оставшиеся дни и рабочий год. Отпуск, уже использованный в текущем году, но без приказа в программе,
вносится тоже как корректировка, с минусом.

Социальные отпуска: в приказе об отпуске по беременности и родам предлагается 126 дней, в приказе об отцовском — 14; для
отпуска по уходу за ребёнком выбирается ребёнок из вкладки «Семья», и период рассчитывается до достижения им 3 лет
(частично оплачиваемый) или с 3 до 4 лет (неоплачиваемый). На следующий день после окончания отпуска договор
возобновляется сам (ночная задача).
