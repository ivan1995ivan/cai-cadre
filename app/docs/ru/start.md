# Стартовая панель

Стартовая панель — первый экран после входа. Она показывает показатели предприятия **на сегодня** и ближайшие сроки.
Руководитель подразделения видит те же показатели, но **только по своим подразделениям**.

## Показатели

| Показатель | Что показывает |
|---|---|
| **Работающих сотрудников** | Работающие сотрудники (в том числе с приостановленным договором) |
| **В отпуске сегодня** | Ежегодные, социальные отпуска, отпуска без сохранения зарплаты, которые приходятся на сегодня |
| **На больничном сегодня** | Листки нетрудоспособности, открытые на сегодня |
| **В командировке / на обучении сегодня** | Служебные командировки и курсы повышения квалификации |
| **Сроки в ближайшие 30 дней** | Сколько оповещений имеют срок в ближайшие 30 дней (красным, если есть срочные) |
| **Новые заявления на отпуск** | Ещё не рассмотренные заявления |
| **Неподписанные приказы** | Проекты приказов (только для тех, кто подписывает приказы) |
| **Приказы без ознакомления** | Подписанные приказы, с которыми сотрудник не ознакомлен под подпись |

Клик по показателю открывает соответствующий список.

**Штатное расписание**: утверждённые, занятые и вакантные единицы, с процентом укомплектованности. Клик — отчёт о
замещении.

**Ближайшие сроки**: первые 8 оповещений (сначала срочные). Все они — в
[Сроках и оповещениях](help:alerts).

**Дни рождения**: у кого день рождения в ближайшие 7 дней.

## Шапка

- **?** (или F1): инструкция для текущего экрана.
- **Колокольчик**: уведомления — сроки, приказы на подпись, заявления на отпуск.
- **Палитра**: тема и расположение меню.
- **RO / RU / EN**: язык интерфейса.
- **Ваше имя**: профиль и выход из системы.

## Открытые окна (нижняя панель)

Каждая открытая страница остаётся вкладкой в нижней панели.
- **Esc** закрывает открытую страницу — форму или список — и её вкладку; открывается соседняя вкладка. Если в форме есть
  несохранённые изменения, программа спросит **«Сохранить изменения?»**: *Да* (сохранить и закрыть), *Нет* (закрыть без
  них), *Отмена* (остаться). Пока открыто окно, выпадающий список или календарь, Esc закрывает их.
- **`` Alt+` ``** (клавиша под Esc) открывает список **Открытые окна**: стрелки или снова `` Alt+` `` — выбор, **Enter** — открыть,
  **цифра 1–9** — сразу открыть окно с этим номером, **Esc** — закрыть список.
- **✕** справа вверху формы делает то же, что Esc; **Закрыть все** — все вкладки.

## Формы и списки на свой вкус

- **Форма** (кнопка справа вверху форм: личное дело, трудовое отношение, приказ, отпуск, больничный, обучение,
  пользователь, подразделение, классификаторы...): расположение полей, как в 1С. Поля стоят в группах горизонтально или
  вертикально, одна в другой, с заголовком, рамкой и шириной (из 24 частей строки); перетаскиваются мышью или
  стрелками, флажок перед полем скрывает его (значение сохраняется; обязательные видны всегда). **Сохранить для меня** —
  только для вас; **Сохранить для всех** (с правом на настройки) — расположение для всех, у кого нет своего.
  **Как было** — форма программы.
- **⚙** в углу таблиц: колонки списка, их порядок и ширина; рядом — сохранение списка в Excel.
