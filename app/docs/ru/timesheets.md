# Табели учёта времени

Табель составляется за месяц по каждому подразделению и **заполняется сам**: из месячного графика отделения (или, если
его нет, из графика работы по трудовым отношениям), из отпусков, больничных листов, командировок и приостановленных
договоров. В ячейке показаны отработанные часы (ниже — ночные часы) или код отсутствия: CO ежегодный отпуск,
CA дополнительный, CFP без сохранения зарплаты, CMT по беременности и родам, CP отцовский, CIC / CICN уход за ребёнком,
CS учебный, ZL оплачиваемые свободные дни, D командировка, F повышение квалификации, CM больничный, S договор
приостановлен, A прогул, IN отгул.

**Ручная правка**: клик по ячейке — смена, отработанные часы (и ночные) или код отсутствия. Ячейки, введённые вручную,
сохраняются при «Пересчитать» (они подчёркнуты); «Пересчитать всё» их стирает.

**Итоги** по строке: отработанные дни и часы, ночные часы, часы в праздничные дни, норма месяца для трудовых отношений
(рабочие дни × часы в день × ставка), часы сверх нормы (+) или неотработанные (−), отсутствия по кодам.

**Порядок работы**: черновик (отделение) → передан в отдел кадров → **закрыт** (больше не меняется; уходит в расчёт
зарплаты). Закрывает и повторно открывает тот, у кого есть право «Рабочее время → Утверждение / подпись».

**Экспорт для 1С Зарплата** (кнопка в списке месяца): файл Excel со всеми табелями месяца — лист «Pontaj» с итогами по
каждому трудовому отношению (табельный номер, ИДНП, отделение, должность, вид, ставка, дни, часы, ночные, праздничные,
норма, сверхурочные, неотработанные, отсутствия по кодам) и лист «Zile» с ячейками по дням.

**Печать**: форма табеля (две строки на сотрудника: часы / код и ночные часы) с подписями заведующего отделением и
составителя.
