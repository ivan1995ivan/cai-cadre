# Классификаторы

Каждый классификатор — отдельная настройка в *Администрирование → Настройки* (найдите его по названию).

- **Должности (CORM)** — должности с кодом по Классификатору занятий CORM 006-21, категория персонала (врачи, средний
  медицинский персонал, младший, административно-хозяйственный…), часы в неделю и дни отпуска. Полный классификатор
  можно загрузить через **Импорт CORM из Excel** (переносятся код и наименование).
- **Специальности** — медицинские, фармацевтические специальности и специальности сестринского дела (для образования,
  аттестации, категорий).
- **Правовые основания** — статьи Трудового кодекса и акты МЗ, которые указываются в приказе как основание. Сверяйте текст
  с действующей редакцией акта на legis.md.
- **Виды приказов** — все приказы (приём, перевод, отпуска, замещение, совместительство, приостановление, прекращение,
  взыскания, аттестация, штатное расписание…), с журналом нумерации, действием на личное дело при подписании, основанием
  по умолчанию и признаком, подаётся ли отчёт в НКСС (IRM19). Виды с пометкой «1C» были в конфигурации 1С «Кадры».
- **Малые классификаторы**, каждый своей настройкой: уровень и форма образования, виды документов (со сроком действия), родство, семейное положение, национальность, причины прекращения,
  взыскания, поощрения, вид занятости, воинский учёт (группа, звания, военные центры — только с включённым
  модулем) и контрольный список при приёме / увольнении.

**Удалить** помечает элемент на удаление (зачёркнут в списке, не выбирается в полях); окончательно он удаляется в
*Администрирование → Удаление помеченных объектов*, только если нигде не используется (в штатном расписании, приказах,
личных делах). Используемый элемент, который больше не нужно выбирать, делают неактивным.

## Кнопка «…» рядом с полями

Везде, где значение выбирается из классификатора (национальность, семейное положение, вид документа, образование,
специальность, должность CORM, причина увольнения, взыскание, военный центр…), рядом
со списком есть кнопка **«…»**. Она открывает классификатор прямо из формы: поиск, **Добавить** новый элемент, исправление
(клик по коду) и **Выбрать** (или двойной клик) — выбранный элемент попадает в поле. Для добавления и исправления нужно
право *Классификаторы → Редактирование*.
