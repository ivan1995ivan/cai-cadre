# Заявления сотрудников

Заявления, поданные сотрудниками из **Моего кабинета**, кроме отпусков: справки (с места работы, о стаже, о зарплате),
изменение личных данных, другие заявления. Заявления на отпуск находятся в *Отпуска → Заявления на отпуск* (их
согласовывает руководитель подразделения, приказ издаёт отдел кадров).

- О новом заявлении отдел кадров получает уведомление (и письмо).
- **Решить** (или двойной клик): **В работе**, **Готово** или **Отклонить**, с коротким ответом («Справку заберите в
  кабинете 12»). Сотрудник получает уведомление с ответом.
- Справки печатаются из карточки сотрудника, кнопка **Печать**.

## Доступ к кабинету
- В карточке сотрудника кнопка **Кабинет**: **Создать доступ** (учётная запись с ролью «Сотрудник» и временным паролем,
  который виден только один раз), **Новый пароль**, **Отключить доступ**.
- В списке сотрудников **Учётные записи для кабинета** создаёт учётные записи для всех работающих сотрудников, у которых
  их нет; список с паролями выгружается в Excel и передаётся сотрудникам.
- Учётная запись создаётся по имени из e-mail сотрудника (ion.popescu) или по табельному номеру (t125). Нужно право
  *Пользователи → Создание*.
