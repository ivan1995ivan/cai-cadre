# Jurnalul de audit

Cine, ce și când a modificat în sistem.

- **Creare / Modificare / Ștergere**: pentru fiecare modificare se vede **valoarea veche → valoarea nouă** (apăsați „+” din stânga rândului).
- **Intrare / Intrare eșuată**: intrările în sistem, cu adresa IP. Multe intrări eșuate la rând pot însemna o încercare de spargere a parolei.

Filtre: perioada, acțiunea, obiectul (tipul înregistrării), căutare după denumire.
Jurnalul nu se poate modifica din interfață.
