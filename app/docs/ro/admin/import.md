# Import din Excel

Pornirea unei baze noi fără 1C. Pașii se fac în ordine, pentru că fiecare fișier se sprijină pe cele de dinainte:
funcțiile (CORM) → specialitățile → subdiviziunile → angajații cu raportul de muncă → actele, familia, studiile,
stagiul anterior. Se văd doar pașii pentru care aveți drepturi.

Pentru fiecare pas: **Descarcă șablonul**, completați-l (antetul se păstrează, ordinea coloanelor nu contează, coloanele
cu * sunt obligatorii), încărcați-l. Sistemul face întâi o **încercare**: arată câte rânduri se adaugă, câte se
actualizează și erorile pe rânduri. Nimic nu se scrie până nu apăsați **Importă**; dacă un rând are eroare, nu se scrie
nimic din fișier.

Angajații: un rând = o persoană și un raport de muncă. Pentru cumul intern repetați persoana pe alt rând. Angajatul
existent se recunoaște după IDNP, apoi după numărul de tabel, deci fișierul corectat se poate importa din nou.
Bifa **Creează în clasificator funcțiile care lipsesc (după denumire)** adaugă funcțiile negăsite în clasificator.

Rândurile statelor de personal se importă din fișa statelor (*Întreprinderea → State de personal → Import rânduri din Excel*).
